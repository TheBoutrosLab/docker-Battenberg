# docker-Battenberg
Boutros Lab Docker image for Battenberg.

This image installs Battenberg `2.2.9` and rewrites the bundled `battenberg_wgs.R` resource paths to match the Boutros Lab cluster layout.

The published container image is available at `ghcr.io/theboutroslab/battenberg`.

# Version
| Tool | Version |
